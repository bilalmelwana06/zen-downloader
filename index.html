How to install

  1. Click Download for Windows above.
  2. Open the downloaded ZenDownloaderSetup.exe.
  3. If Windows shows a blue screen, click More info → Run anyway (the app is safe).
  4. Finish the setup, open Zen Downloader Pro, and start downloading.
Note: Because the app is new and not yet code-signed, Windows SmartScreen may show a warning the first time. This is normal for new apps — just choose More info → Run anyway.
